# es40

[ES40-Emu/es40](https://github.com/ES40-Emu/es40) emulates an AlphaServer ES40
and runs OpenVMS, Tru64 and NetBSD/alpha.

## Console

In the emulator's cfg, give each serial port a TCP port:

```
serial0 = serial { port = 21000; }
serial1 = serial { port = 21001; }
```

List both in the guest conf's `serials`, console first. Before 0.95 es40 would
not start until every configured serial had a client, and emuctl holds the
second one open for that reason. From 0.95 a port can carry
`wait_for_connection = false`, or be left out; keep `serial0` waiting, so
nothing printed before the supervisor attaches is lost.

Serial ports listen on every interface unless the cfg sets `listen_address`.

## Conf

```ini
name     = alpha
os       = OpenVMS Alpha 8.4
emulator = es40 0.95
workdir  = /srv/emu/alpha
command  = /usr/local/bin/es40 es40.cfg
disks    = dka0.img
serials  = 21000,21001
broker   = 2300

boot.1   = >>> | boot dka0
ready    = Username:
halted   = P00>>>
boot_timeout = 1200

stuck.1  = Please enter date and time
stuck.2  = waiting to form or join
```

For Tru64 or NetBSD use `ready = login:`.

## Things worth knowing

- **Stopping.** es40 has no power button to press from outside, so
  `stop_mode = signal` is a power cut unless the guest is already at `P00>>>`.
  Shut the OS down first (a `stop_command` that logs in and runs the OS's
  shutdown), after which the guest reads `halted` and a stop loses nothing.
- **Console queue (0.95 and later).** Each console client has a 64 KiB output
  queue; es40 drops a client that falls behind and keeps running. emuctl
  reconnects and notes the gap in `console.log`.
- **Clock (0.95 and later).** The guest clock is seeded from the host's local
  time unless the cfg's `ali` device sets `timezone = "utc"`. If a guest that
  kept UTC under an earlier release moves to 0.95 on a host in another zone,
  OpenVMS sees time go backwards and stops at `Please enter date and time`.
  The `stuck.1` line above makes that visible in `emuctl list`.
- **Building.** The JIT is off unless you build with
  `-DES40_DISABLE_ASMJIT=OFF`. `es40 --version` lists `AsmJit` among its
  features when it is in.
